Overview

The timeline lays out model launches horizontally so release cadence can be compared across companies and product lines at a glance.

It includes company rows, compact product-line lanes, filtering by model category, month and year guides, zoom controls, release-gap labels, and a live Today marker.

Project Scope

  • Frontier and open-source LLM release tracking
  • Coding harness, image generation, video generation, and 3D generation categories
  • Interactive filters for reading dense timeline sections
  • GitHub Pages deployment through a Vite build pipeline
